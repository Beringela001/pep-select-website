# Responsive and Accessibility Standards

## Width matrix

Review at least:

- 1440px
- 1280px
- 1024px
- 768px
- 480px
- 430px
- 390px
- 375px
- 360px
- 320px

Also test ultrawide full-screen and half-screen browser layouts when admin or dashboard containers can become narrow independently of the viewport.

## Mobile rules

- Create a mobile information hierarchy rather than hiding random desktop content.
- Keep primary actions reachable without excessive scrolling.
- Use full-width form controls where appropriate.
- Avoid horizontal body scrolling.
- Keep cards at useful reading widths.
- Avoid isolated labels that create excessive vertical gaps.
- Keep menus, drawers, and accordions keyboard and screen-reader accessible.
- Ensure floating cart, chat, rewards, and notification controls do not cover page actions.

## Accessibility baseline

- Semantic headings
- Programmatic labels
- Visible focus
- Keyboard navigation
- Escape behavior for modal interfaces
- No keyboard traps
- Status text beyond color
- Reasonable contrast
- Comfortable touch targets
- Associated validation errors
- Reduced-motion behavior
- Meaningful link and button names

## Required states

Test:

- Logged out
- Logged in
- Empty
- Loading
- Success
- Validation error
- Server error
- No results
- One result
- Many results
- Long name or identifier
- Missing optional image
- Keyboard-only
- Mobile drawer open
- Browser resized without reload
