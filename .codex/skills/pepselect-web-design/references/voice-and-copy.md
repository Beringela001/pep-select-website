# Voice and Copy

## Personality

Calm, informed, transparent, practical, and human. Professional without sounding corporate. Clinical-modern without sounding like a hospital or legal notice.

## Reading style

- Prefer short to medium sentences.
- Use headings that state the actual purpose of the section.
- Use plain language for account, tracking, shipping, payment, and validation states.
- Explain technical testing terms only when the explanation helps a decision.
- Keep legal and research-use language accurate but visually subordinate to the primary task.

## Preferred language

Use verbs such as:

- document
- publish
- verify
- review
- match
- track
- test
- report
- compare
- confirm
- preserve

Use nouns such as:

- batch
- report
- testing history
- laboratory documentation
- order status
- shipment
- account
- evidence
- record

## Avoid

- Best in the industry
- Unmatched quality
- Premium because we say so
- Guaranteed purity unless the exact documented context supports the statement
- Revolutionary as filler
- Game-changing
- Elite
- Exclusive access
- Buy with confidence as a substitute for evidence
- We do not sell confidence
- Not a big-box operation
- Focused, hands-on brand
- Frictionless ordering
- Broad claims about consistency and reliability without supporting detail

## Page-copy pattern

1. State the customer's task or question.
2. Explain what Pep Select provides.
3. Show the relevant evidence or action.
4. Clarify limits, status, or next step.

## Microcopy

Buttons must describe the destination or action:

- View Testing History
- View Latest COA
- Track Order
- Review Order Details
- Save Address
- Continue with Google

Avoid generic labels such as Learn More when a precise label is available.

Errors should explain recovery without exposing private information. Public tracking failures should not confirm whether an order number or email exists independently.
