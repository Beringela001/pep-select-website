# Template parts

Version 0.4.0-beta.2 provides the default coded shell parts under `header/` and `footer/`, plus administrator-only product-first homepage preview parts under `home/`.

The shell parts render on supported front-end requests while the child theme is active. The homepage parts render only for an authorized front-page `?pepselect_home_preview=1` request. An authorized `?pepselect_legacy_shell=1` request and protected editor or non-front-end contexts retain Elementor Header #1323 and Footer #391. No search-results, WooCommerce, or Elementor template override is included.
