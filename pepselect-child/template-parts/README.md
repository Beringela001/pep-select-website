# Template parts

The theme provides the default coded shell parts under `header/` and `footer/`, plus product-first homepage parts under `home/`.

The shell parts render on supported front-end requests while the child theme is active. The administrator-only `?pepselect_home_preview=1` control remains available for front-page verification. Protected non-front-end contexts retain normal WordPress behavior. No search-results or WooCommerce template override is included.
