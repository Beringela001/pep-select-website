# Template parts

Version 0.3.1 provides the default coded shell parts under `header/` and `footer/`.

These template parts render on supported front-end requests while the child theme is active. An authorized `?pepselect_legacy_shell=1` request and protected editor or non-front-end contexts retain Elementor Header #1323 and Footer #391. No search-results, WooCommerce, page-content, or Elementor template override is included.
