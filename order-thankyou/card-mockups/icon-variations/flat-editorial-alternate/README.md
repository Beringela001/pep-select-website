# Flat editorial alternate icon set

Alternate four-icon family created without changing the approved thank-you
card artwork.

This direction is fully 2D. Depth comes only from overlapping shapes, small
offset color layers, and restrained low-opacity shadows. It intentionally
avoids bevels, simulated materials, dramatic perspective, glossy rendering,
and game-style icon treatment.

The four concepts remain Verified COA, Additional Product Information,
A Little Gift From Us, and Have Questions.

The official vector brand mark should replace generated marks in production.
